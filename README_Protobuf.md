# Protobuf 代码生成指南

## 📁 文件结构

```
Server_MyDemo/
├── Protos/
│   └── messages.proto              ← Proto 定义文件（源文件）
├── GeneratedCodes/
│   └── Messages.cs                 ← 生成的 C# 代码（自动生成，勿手动修改）
└── generate_proto.bat              ← 生成脚本
```

## 🔧 如何重新生成 C# 代码

### 方法1：双击运行（推荐）

直接双击 `generate_proto.bat` 文件即可。

### 方法2：命令行运行

```bash
cd E:\unity\Server_MyDemo
.\generate_proto.bat
```

### 方法3：手动执行 protoc 命令

```bash
E:\unity\Protoc\protoc-21.1-win64\bin\protoc.exe ^
    --proto_path=Protos ^
    --csharp_out=GeneratedCodes ^
    Protos\messages.proto
```

## 📋 生成后的操作

### 1. 服务器端（自动完成）
- 生成的 `Messages.cs` 已在 `GeneratedCodes/` 目录中
- Visual Studio 会自动识别并编译

### 2. 客户端（需要手动复制）

**重要：每次修改 .proto 文件后，必须将生成的 Messages.cs 复制到客户端！**

```bash
# 复制到 Unity 项目
copy "E:\unity\Server_MyDemo\GeneratedCodes\Messages.cs" "E:\unity\My Demo\Assets\Code\NetWork\ProtoBuf\GeneratedCodes\Messages.cs"
```

## ⚠️ 注意事项

### ❌ 不要手动编辑 `Messages.cs`
- 文件头部有注释：`// Generated by the protocol buffer compiler. DO NOT EDIT!`
- 所有修改应该在 `.proto` 文件中进行
- 修改后重新生成会覆盖所有更改

### ✅ 正确的工作流程

1. **编辑** `Protos/messages.proto`（添加/修改消息定义）
2. **运行** `generate_proto.bat`（生成新的 C# 代码）
3. **复制** `GeneratedCodes/Messages.cs` 到客户端项目
4. **测试** 编译并测试功能

## 🐛 常见问题

### Q: 提示找不到 protoc.exe？
**A:** 检查路径是否正确：
```bash
# 确认工具存在
dir "E:\unity\Protoc\protoc-21.1-win64\bin\protoc.exe"
```

### Q: 生成失败，提示语法错误？
**A:** 检查 `.proto` 文件语法：
- 使用 `syntax = "proto3";`
- 每个字段都有编号
- 字段名使用 snake_case

### Q: Unity 报错 "The type or namespace name 'GameNetwork' could not be found"？
**A:** 
1. 确保 `Messages.cs` 已复制到正确位置
2. 在 Unity 中点击 `Assets -> Reimport All`
3. 检查命名空间是否为 `GameNetwork`

### Q: 如何添加新的消息类型？

在 `messages.proto` 中添加：

```protobuf
// 在 enum MsgID 中添加新ID
enum MsgID {
    // ... 已有的 ...
    C2S_NewMessage = 100;  // 新增消息ID
}

// 定义消息结构
message NewMessageReq {
    string field1 = 1;
    int32 field2 = 2;
}

message NewMessageResp {
    bool success = 1;
}
```

然后重新运行 `generate_proto.bat` 即可。
